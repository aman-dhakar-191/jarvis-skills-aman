# Skill: research-deep

Conduct comprehensive, multi-source research with stringent source ranking and verification protocols.

Use when: Aman requests thorough, well-structured synthesis of reliable information from multiple vetted sources.

Steps:
1. Gather data from a minimum of three independent sources whenever possible.
2. Prioritize official documentation, release notes, and verified primary sources over blogs, forums, or single-person opinions.
3. Flag any claims based on a single source as unverified or provisional.
4. Synthesize gathered information into a concise, clear written report.
5. Include a final summary table listing each claim, the best supporting source, source type (e.g., documentation, blog, forum), and a confidence rating.

Output: A structured summary brief highlighting key verified claims with source transparency.

Constraints: Avoid unverified or uncertain information. Objective clarity and rigorous source evaluation are mandatory.
